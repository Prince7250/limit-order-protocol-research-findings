# File-level Solidity notes

This directory mirrors every `contracts/**/*.sol` source path and contains a corresponding `.md` note. Each note identifies the source role, exports or principal functions, callers/dependencies where material, and security properties or assumptions. JavaScript tests, deployment scripts, configuration, workflows, prose docs, and generated deployment manifests are classified in `../01-repository-inventory.md` and analyzed collectively in `../05-test-suite-analysis.md` and `../07-dependencies-and-trust-boundaries.md`.

The notes are source analysis, not evidence that any source is deployed, audited, or free of defects. Consult `../PROGRESS.md` for execution and dependency limitations.
